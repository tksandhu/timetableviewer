# Campus Time

A front-end-only timetable viewer built from the July–December 2026 workbook. For Years 1–4, choose an individual group code such as 1A11; its matching practical subgroup and shared lecture group are included. The postgraduate schedule is available as a combined view.

## Open or publish it

Open `index.html` in a browser, or upload that single file to the root of a GitHub repository and enable GitHub Pages from the `main` branch and `/(root)` folder. The HTML file contains the styles, scripts, and timetable data, so no other files are required for the site to run.

The site does not require a database, account, or backend. The separate CSS, JavaScript, and JSON files in this folder are included as editable source copies.
