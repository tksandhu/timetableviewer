# Campus Time

A front-end-only timetable viewer built from the July–December 2026 workbook. For Years 1–4, choose an individual group code such as 1A11; its matching practical subgroup and shared lecture group are included. The postgraduate schedule is available as a combined view.

## Open it

Open `index.html` in a browser. The timetable data is bundled in `data/timetables.js`, so the selectors also populate when opening the file directly. A static web server works too.

The site does not require a database, account, or backend. `data/timetables.json` is included as a readable copy of the schedule data.
